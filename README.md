# Kanchi Battle Royale Android App

This project contains a simple Android game prototype inspired by the browser battle royale concept you supplied.

## Requirements
- Android Studio Ladybug or newer
- JDK 17
- Android SDK 34

## Open in Android Studio
1. Open Android Studio.
2. Choose "Open" and select this folder.
3. Let Gradle sync.
4. Run the app on an emulator or Android device.

## Notes
- The game is a mobile-friendly prototype with drag movement and hold-to-fire controls.
- This is a prototype, not a complete commercial packaging project.
